# 🐼 Pandas: Teoria e Exercícios

Este repositório reúne **resumos teóricos**, **exercícios práticos** e **notebooks explicativos** sobre a biblioteca Pandas, um dos pilares da análise de dados em Python. O objetivo é consolidar os conhecimentos adquiridos por meio da prática e transformar o conteúdo estudado em um material de consulta e portfólio.

## 📘 Objetivos
- Compreender os principais conceitos e métodos do Pandas.
- Resolver exercícios aplicados com datasets reais.
- Criar um acervo de estudos bem organizado e reutilizável.
- Desenvolver fluência na manipulação e análise de dados.
